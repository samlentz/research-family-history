# Family History Research

A Codex skill for building a family tree, finding stories and photographs, and saving the records behind each discovery.

## Suggested prompt

> Use `$research-family-history` to research my family tree. Here are as many family names as I can remember. For each person, I’ve included where they’re from or where they lived, and how they’re related to me or someone else on the list.
>
> - [Name or nickname] — [town, state, or country] — [relationship]
> - [Name or nickname] — [town, state, or country] — [relationship]
>
> Some spellings and relationships are guesses. See how far back you can trace the family, look for stories about their lives, and save the records behind what you find. Tell me which connections are still uncertain. Use online sources and please don’t contact anyone.

## Newspaper tip

If you have a Newspapers.com subscription or trial, sign in through your browser and tell Codex it can use that browser to search the archive. Ask it to look for names in hometown papers, read the full page around each match, and save relevant clippings with the newspaper name, date, and page number.

## Installation

Run this in your project folder, then open the project in Codex and use the prompt above.

```bash
git clone https://github.com/samlentz/research-family-history.git .agents/skills/research-family-history
```
